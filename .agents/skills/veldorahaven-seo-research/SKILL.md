# VELDORAHAVEN SEO RESEARCH

Find the keywords VeldoraHaven should own and translate them into concrete
on-page decisions — titles, headings, copy direction, and content gaps.

---

## CONTEXT

VeldoraHaven targets high-intent buyers researching premium outdoor living products.
These are considered, high-ticket purchases (€3,000–€50,000+). The buyer journey is
long: research → shortlist → request quote / contact. SEO here is less about volume
and more about ranking for the exact terms a ready-to-buy customer uses.

Markets: Scandinavia (SE/DK/NO), DACH, Benelux, UK. Language mix: Danish + English
(primary), with Swedish/Norwegian consideration. Research accordingly.

Categories: saunas (barrel, cabin, infrared, steam), cold plunges, hot tubs, swim
spas, outdoor kitchens, fire features, heaters/accessories.

---

## RESEARCH PROCESS

### 1. Understand the scope
- Which page type? (Product / Collection / Blog / Homepage)
- Which category and specific product?
- Which market language? (Danish, English, or both?)
- What's the existing title/description if optimizing an existing page?

### 2. Keyword discovery (3–4 searches)
Search for:
- The product type + "buy" or "price" in the target language
- Branded terms: "[brand name] sauna", "[brand name] pris"
- Category browse terms: "udendørs sauna", "outdoor sauna Denmark", "buy barrel sauna"
- Long-tail intent: "how to choose a sauna for home", "barrel sauna vs cabin sauna"

Look at:
- Google autocomplete (infer from search result snippets and "People also ask" boxes)
- Competitor page titles and H1s visible in search results
- Forum/Reddit threads about buying these products (how do buyers phrase their questions?)

### 3. Classify by intent
| Intent type | Example query | Page type to target |
|-------------|---------------|---------------------|
| Transactional | "køb udendørs sauna" | Collection / PDP |
| Comparative | "barrel sauna vs cabin sauna" | Blog / PDP |
| Informational | "how long to heat barrel sauna" | Blog |
| Navigational | "Auroom sauna pris" | PDP / Brand page |
| Local | "sauna leverandør Danmark" | Contact / About |

### 4. Competitive content gap check
- Search for the 2–3 main keywords
- Note which VeldoraHaven competitors rank on page 1
- Note what angle they use (price focus? lifestyle? technical specs?)
- Identify what's missing or weak in the top results — that's the opportunity

## QUALITY STANDARDS

- Prefer keywords with clear buyer intent over pure volume.
- Note when a keyword is highly competitive (dominated by large retailers or review sites) — VeldoraHaven may need a long-tail angle instead.
- Keep meta titles under 60 characters, descriptions under 155.
- If researching in Danish: verify the natural phrasing by checking how Danish e-commerce sites actually write it, not just translation.
- Flag if a keyword is ambiguous (informational vs transactional) — the page type must match intent.
