# 48. PARTNERSHIP STATUS RULE

AI agents MUST distinguish between:

**Confirmed Partner**

**Partnership Discussions**

**Future Target**

Never imply a partnership exists when it is only being discussed.

This distinction is important for:

- Website copy
- Brand pages
- Navigation
- SEO
- Marketing
- AI-generated content
- Product descriptions
- Social media
- Internal planning

Only move a brand to **Confirmed Partner** when VeldoraHaven has explicitly established that the partnership is finalized.
